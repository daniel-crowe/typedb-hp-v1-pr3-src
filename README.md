# TypeDB homepage v1

Localhost Next.js page. One route: `/`. Not a restyle of live typedb.com. Not a deploy.

## Run

```bash
cd site
npm install
npm run dev
```

Open http://localhost:3000

## v1 sections

Hero, S1 stack/process tabs, S2 meaning, S3 jobs, S4 insight, S5 suite, S6 0→1, S7 community + named work.

Fonts: Darkmode + Monaco from live typedb.com. No Magic Patterns.

## Scripts

- `npm run dev` — local preview
- `npm run build` — production build (local only)
- `npm run lint` — eslint
